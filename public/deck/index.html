01 The problem

Knowledge work is leaking out of your week.

You read, watch, and learn constantly — but the insights never make it into Monday morning. Notes go cold. Tabs close. Tools fragment. Nothing closes the loop from input to action.

Overload
Too many sources

YouTube, articles, PDFs, voice memos, Slack — knowledge piles up in twelve different inboxes.

Loss
Notes go cold

You highlight, you screenshot, you forget. Two weeks later the insight is gone and the link is dead.

No execution
Learning ≠ doing

You finish a great talk and write nothing down. No task gets created. The idea evaporates.

Forgetting
No retrieval

You know you saved it — somewhere. Search by keyword fails. Your past self is unreachable.

No focus
Mornings start cold

No daily brief, no priorities, no “here’s what changed overnight.” You re-orient from scratch.

Fragmentation
Six tabs, one brain

Notion, Apple Notes, Readwise, Calendar, Tasks — none of them know about each other.

02 The solution

One loop. From any input, to a daily action.

Recall X247 turns scattered inputs into a queryable knowledge vault and a daily plan. Capture anything, recall it semantically, act on what matters today, review tomorrow.

Step 1

Capture

Drop a link, a PDF, a voice memo or a thought. Specialist agents extract, summarize and tag.

Step 2

Recall

Three-tier semantic search returns cited passages from your vault — not the open web.

Step 3

Act

Tasks, calendar events and study sessions auto-link back to the source memory.

Step 4

Review

Morning briefing, inbox queue and flashcards close the loop and feed tomorrow.

05 Feature · Capture

Knowledge Capture — anything in, structured out.

  • Five input types: YouTube, web articles, PDFs, plain notes, and voice memos.
  • Specialist extractors per source — transcripts for video, readability for the web, OCR for PDFs.
  • Auto-summary, key points and tags generated on save, no second click.
  • Source preserved verbatim so every later answer can cite the original passage.
  • Voice mode with live transcription and a clean “Checking Live availability” status.

06 Feature · Neural Recall

Neural Recall — three-tier semantic search with cited sources.

  • Tier 1 — Vector search over titles, summaries and chunks for instant matches.
  • Tier 2 — Cross-encoder rerank promotes the passages that actually answer the question.
  • Tier 3 — Agent synthesis stitches a cited answer from the top passages.
  • Every claim links back to the source memory, with the exact quote highlighted.
  • No web fallback by default — answers come from your vault, not the open internet.

11 Feature · Agent Hub

Agent Hub — multi-agent chat with live streaming and a workflow trace.

  • Seven specialist agents coordinated by an orchestrator: Capture, Recall, Plan, Briefing, Live, Library, Workspace.
  • Live SSE streaming — tokens, tool calls and partial results arrive as they happen.
  • Workflow trace panel shows which agent ran, what it called, and how long it took.
  • Codename masking keeps internal agent identifiers out of user-facing copy.
  • Command palette jumps from anywhere to the agent, with the inbox count surfaced inline.

12 Feature · Knowledge views

Graph, Timeline & Workspace — three lenses on the same vault.

  • Knowledge Graph — nodes are memories, edges are shared topics, people and projects.
  • Timeline — every capture, task and event on one scrollable spine, by day.
  • Workspace — a freeform canvas to assemble memories into a thesis, brief or doc.
  • Cross-linked — clicking a node anywhere opens the same memory detail with full context.
  • Filter once, applies everywhere — domain, source, project carry across views.

Inbox & review — one queue between input and action.
